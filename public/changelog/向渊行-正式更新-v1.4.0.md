# 【浏览器里的集成工业】向渊行 新配方更新

# 素材更新
更新了一批素材,调整了一些设备蓝图模式下的设备图以及图标，包括协议核心的图标。

# 增加了净水节点
应部分管理员的要求，本次更新新增了净水节点。
净水节点摆放时会强制吸附在地图边缘。除了游戏内提供的30点污水转化为1点壤晶废液外，还增加了指定输出速率的功能，用于模拟其他地图的产线向净水节点提交污水的情况。
在选项中切换到手动模式后，输入每分钟生产数量，净水节点就会每分钟产出指定数量的壤晶废液，不管他收到了多少污水。

此外抽水泵现在也改为强制吸附在边缘了，以前在其他位置摆放抽水泵的产线，管理员可以将抽水泵替换为暗管出口，并指定无限生产清水

# 准入口控速

和游戏内一样，本次更新新增了准入口控速功能，可以指定每分钟最多流过物品数量。

# 重叠设备菜单

和游戏内已有，本次新增重叠设备点击菜单，现在点击重叠设备的格子，会弹出菜单要求选择设备。

# 移动端操作优化

移动端放置设备和蓝图时，如果拖动视口导致正在放置的蓝图或设备移出屏幕外，则会自动将设备移动回屏幕。（游戏内已有功能）
