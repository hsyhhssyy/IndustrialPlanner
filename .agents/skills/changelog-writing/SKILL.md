# 更新日志写作

## 能做什么

- 按 [更新日志写作规范](references/writing-guide.md) 编写完整日志，或向现有日志追加用户可感知的 `feat:`、`fix:` 变更。

## 不能做什么

- 不得把 `dev:` 类内部改动写入更新日志，不得自行翻译物品、设备或配方名称。
- 追加自动生成内容时，不得修改用户手动撰写的内容，也不得重复已有条目。
