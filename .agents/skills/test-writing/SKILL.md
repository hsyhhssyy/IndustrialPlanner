# 测试编写与单项执行

## 能做什么

- 创建、修改测试或处理测试失败时，读取 [测试处理规则](references/testing-policy.md)。
- 创建新测试前，必须同时读取 [测试架构设计通则](../../../.docs/common/测试/测试架构设计通则.md)。
- 执行用户明确指定的测试集，并按项目的 Vitest project 划分报告结果。

## 不能做什么

- 不得为了让失败测试通过而擅自修改断言或测试逻辑。
- 不得用本 Skill 代替 `full-check` 执行完整代码质量检查。
- 不得在已有 vitest 或 build 进程运行时并发启动第二个同类进程。

## 单例执行（强制）

`vitest` 与 `build` 为全机单例。执行任何测试或构建前，必须按 [单例执行规则](references/single-instance-execution.md) 检测在跑进程并判定处理：

- 检测到的进程启动时间晚于你的最后改动，且测试范围覆盖本次需求时，允许复用：等待其结束并读取退出码与日志作为本次结果。
- 进程启动早于你的最后改动时结果无效：等待其结束后再启动自己的执行，不得并发。
- 不得终止他人进程，也不得用 watch 模式进程充作执行结果。
