# 测试编写与单项执行

## 能做什么

- 创建、修改测试或处理测试失败时，读取 [测试处理规则](references/testing-policy.md)。
- 创建新测试前，必须同时读取 [测试架构设计通则](../../../.docs/common/测试/测试架构设计通则.md)。
- 执行用户明确指定的测试集，并按项目的 Vitest project 划分报告结果。

## 不能做什么

- 不得为了让失败测试通过而擅自修改断言或测试逻辑。
- 不得用本 Skill 代替 `full-check` 执行完整代码质量检查。
