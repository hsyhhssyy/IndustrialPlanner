# 项目文档写作

## 能做什么

- 按 [通用写作标准](references/writing-standard.md) 创建或维护可脱离对话独立成立的长期项目文档。
- 编写 stage 或 bug 文档时，必须同时读取 [专项文档要求](references/document-types.md)。

## 不能做什么

- 不得依赖聊天上下文、只写结论不写原因，或把 AI / 开发者决策伪装成用户要求。
- 不得让已失效方案与当前方案并存，也不得把局部修补描述成系统性规则。
