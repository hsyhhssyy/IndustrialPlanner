# 公开 Issue 分析输出格式

```markdown
## Issue 概要

- issue：`#1234`
- 版本 / 浏览器 / 设备：
- 涉及功能 / 设备 / 配方：
- 用户现象：

## 附件概览

- 实际可读文件 / 截图：
- 缺失或未上传的证据：

## 关键证据

- issue 正文 / 评论：
- 截图分析：
- 控制台输出：
- 代码依据：

## 根因判断

- 直接结论：
- 证据链：
- 当前主线是否可能已修复：

## 修复方案

1. 代码 / 数据层修复
2. 需要补充的测试或验证
3. 如属于不支持场景，如何限制入口或改进提示

## 给用户的建议

- 临时绕过方案：
- 是否建议升级或刷新：

## 置信度

- 高 / 中 / 低
- 还缺什么证据
```
